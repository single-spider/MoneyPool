# MoneyPool user guide
## Start
In demo mode select a sample person using View as. In live mode sign up and set profile name and UPI ID. Your group members can see your UPI ID.
## Groups and friends
Create a group; send its private invitation code to members who have accounts. Join group accepts that code. Friends lists people from shared groups. Balances remain separate per group.
## Expenses
Select a group and Add expense. Enter title, amount and category. Select people included. Equal splits distribute paise exactly; exact splits must sum to total, percentages to 100, shares set proportional weights. The payer is your current account. Activity shows expense history, search and filters. Edit or reverse your own expense; original history remains.
## Pay
Select Pay beside someone you owe. Enter full or partial amount. Scan QR or open UPI app (live mode only). Check recipient and amount before paying. Report transaction reference after successful transfer. Recipient must check bank and confirm receipt. Pending payment never reduces debt.
## Demo walkthrough
Pay Riya INR 200 against sample INR 500 debt. Scan demo QR for text, click Simulate payment, submit generated reference. Switch View as to Riya, open Payments and confirm simulated receipt. Switch back to Alex: debt INR 300. Reset demo in Settings.
## Insights
Shows personal expense share by category, excluding reversed records. No bank data is imported.
## Help
If a payment is uncertain, do not pay again before checking bank and existing request. If disputed, contact recipient. MoneyPool cannot independently verify a personal UPI transfer.
